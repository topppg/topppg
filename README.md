# Giorgio Sarno

**AI Software Engineer at Replika**

My work centers on large language model inference, from serving models efficiently to planning GPU capacity. I also build infrastructure for AI agents, covering tool use, background tasks, and coordination across multiple agents, and I contribute to a memory layer that supports them.

Before this, I worked in data platforms and production machine learning. I designed and deployed custom embedding models for matching industrial parts, and I led a team that brought time series models into production for fleet monitoring. Earlier still, my PhD research in Marseille explored numerical approaches to quantum gravity. Along the way I wrote open source C libraries, including sl2cfoam, with CUDA kernels for GPU parallelization.
